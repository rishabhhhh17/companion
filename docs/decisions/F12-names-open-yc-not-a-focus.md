# F12. Names are open; YC is not a focus

- **Status:** Fixed. Founder decision; do not reopen without the founder. Updated 7 Oct 2026 after review.
- **Date:** 2026-10-06
- **Source:** product_research.md section 1, decision 12
- **Related:** F04, F06, F10

## Decision
YC is not a goal that shapes the plan; we build for users. No names are decided: "Companion", "Curious", "Geeked" and the character names are working names.

## Why
- YC as a goal shaping the plan was dropped in favour of building for users (product_research.md section 11).
- All names will change (product_research.md header).
- Many obvious names are taken or risky: Autopilot, Pilot, Copilot, Clicky, Jarvis, Sidekick, and anything like Claude (product_research.md section 11).

## What this means for the build
- Treat every product, path and character name as a placeholder. Keep names in one strings file, never in logic (AGENTS.md rule 21).
- Users can already rename any character. Spark, Prism, Loop, Orb and Pebble are working names too (product_research.md sections 3, 4).
- Feature names avoid taken words. Drive mode replaced Autopilot (product_research.md section 11).
- Branding may say "Powered by Claude", never "Claude Code" (product_research.md section 15). A plain factual sentence that Companion runs Anthropic's Claude Code is allowed, as long as "Claude Code" is never a feature name, UI label or logo (technical_research.md section 3; T03).
- Final names follow a shortlist, a clearance check, and claiming every handle on one day (product_research.md sections 16, 20).
- Progress is measured by users: installs and first ships, never views, and finished things per active user (product_research.md sections 16, 17).

## What it rules out
- Section 11 row: YC as a goal shaping the plan, replaced by building for users.
- Section 11 row: the names Autopilot, Pilot, Copilot, Clicky, Jarvis, Sidekick, or anything like Claude.
- Naming or styling anything as Claude Code (technical_research.md section 3).
- Hard coding any name into logic.

## Revisit only if
The founder decides to. Names close when the founder picks final names after shortlist and clearance (product_research.md section 20).
