## Scope and coverage

**Scope.** This review covers Squibby's entry path on Mac, in the order a new user meets it:
1. The first run (`app/src/onboarding.tsx`, `app/src/firstLook.tsx`).
2. Home on its Now view (`app/src/card.tsx` from about line 1440, `app/src/recentList.tsx`, `app/src/changesCard.tsx`).
3. The notch panel (`app/src/island.tsx`, `app/src/islandPanel.tsx`).

All styling is in `app/src/style.css`, where the later layers M42 and M43 win. All copy is in `app/src/strings.ts`. The scope was narrowed to the path every user passes because the whole app is too large to review well. Settings, What I did, Learn, Memory, the character and the pointer were left out and were not reviewed. Code was read only in `/Users/rishabhkapadia17/Developer/companion-wt/m36-type`. No file was changed, no git was run and no tests were run.

**Stack.**
- Tauri 2 desktop app, with React 18 and TypeScript pages.
- Plain CSS with tokens on `:root`, no component library.
- Sizes are in rem over a 14 px root, and the Text size setting changes `data-text` on the root.
- Home is a 640 px wide panel, at most 640 px tall (`island.rs` HomeSize). It is Night (dark) by default, with Deep sea and Paper themes.
- The notch panel is 400 px wide and at most 240 px below the notch row (`island.rs` PANEL_MAX).

**Project conventions found in recon.**
- `AGENTS.md` (writing style: plain words, no em dashes, compound words written open; rule 21: names live in `protocol/names.json`, every line lives in `strings.ts`).
- `docs/design/look.md` (type scale 12/13/15/16/19/22 with "no other sizes", reply measure 45 to 70 characters, three status colours).
- The header comment of `style.css` (one strong ease out, four durations, press scale .97).
- The header of `strings.ts`.
- The guards in `app/src/a11y.test.ts` (contrast pairs, focus, reduced motion) and `app/src/look.test.ts` (rem sizing, no fixed heights on text).
