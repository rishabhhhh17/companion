## Clicky (idea: pointing through the Computer Use tool)

`runner/src/aim.ts` uses a technique read in https://github.com/farzaa/clicky (`leanring-buddy/ElementLocationDetector.swift`): ask Anthropic's Computer Use tool where to click, declaring the picture's own size so it is not stretched, and read the coordinate it answers with. The code is new. The multi monitor idea (look at the other displays when the place is not on the one you are on) was also prompted by reading that project.
